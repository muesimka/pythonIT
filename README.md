# Task Manager

Десктопное приложение для управления задачами.  
Версия **0.2.0** · интерфейс на **tkinter** · чёрно-красный дизайн.

---

## Возможности

- Просмотр списка задач
- Добавление задачи (название + описание)
- Удаление задачи (с подтверждением)
- Сохранение в файл `saves.txt`
- Горячие клавиши:
  - `Ctrl+L` — список задач
  - `Ctrl+N` — новая задача
  - `Esc` — главное меню
  - `Enter` — сохранить (в форме добавления)
  - двойной клик по задаче — удалить

---

## Запуск

```bash
python main.py
```

Требуется Python 3.10+ (используется стандартный модуль `tkinter`).

## Формат данных

Задачи хранятся в `saves.txt` построчно:

```
Название | Описание
```

Файл создаётся автоматически при первом запуске.

---

## Экраны

1. **Главное меню** — счётчик задач, кнопки «Посмотреть», «Добавить», «Выход»
2. **Все задачи** — список, удаление, обновление
3. **Новая задача** — поля названия и описания
